# Xartus: <strong>Xarr</strong>ay <strong>t</strong>hrough NeX<strong>us</strong>


This library has two main parts, and some utilities.

1. The `data_converter` and `data_source` allows reading any data into a NeXus file.
2. Integration with xarray: see {doc}`Notebooks/xarray`.
3. Utilities for common requirements when reading and processing data.
4. `plotting` adds alternate plotting to pcolormesh, and plotting slices of a dataset. See {doc}`Notebooks/imshow_sparse`
